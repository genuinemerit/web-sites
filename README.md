# web-sites

David's static-site properties — `taiji`, `spain`, `comunidad`,
`movement`, `play`, `music`, `callejerez` — rebuilt on Frozen-Flask
(Flask + Jinja2 for development, frozen to static HTML for deployment).

Design history and rationale live under `planning/` (pre-build
discussion) and `design/` (build-phase decisions); see
`planning/architecture.md` for the full technical picture and
`planning/target-sites.md` for what each site is and why. Legacy-droplet
review material lives under `legacy/`.

Housekeeping rules for working in this repo are in `CLAUDE.md`.
